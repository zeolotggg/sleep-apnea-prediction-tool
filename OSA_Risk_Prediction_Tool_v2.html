Computation: Nomogram → total points → LP → probability.
Note on Hemoglobin: The model uses a sex-specific z-score (Male: μ=152.6181, σ=5.7128;  Female: μ=136.1800, σ=4.9982), so the same raw Hb value can score very differently for males vs. females. e.g. Hb=150 g/L → z=−0.46 in males (typical) but z=+2.77 in females (top 0.3%), and the latter contributes far more points. This reflects the clinical reasoning that Hb unusually high for one's sex suggests chronic hypoxia.
